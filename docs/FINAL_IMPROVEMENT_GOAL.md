# 최종 성능 개선 목표

2026-09-04 사용자 요청에 따라 완료까지 지속하는 목표다. 학습 준비나 코드 테스트만으로
완료 처리하지 않는다. `OPERATIONAL_V4_HANDOFF_PLAN.md`의 실제 완료 기록을 이어서 사용한다.

## 완료 조건

1. YOLO 검출기를 유지한다. AIHub 9종을 주 데이터로 사용하고, 2026-08-01 이후
   검증된 운영 사진만 소량 섞는다. 쓰레기 한 개의 실제 YOLO proposal crop으로
   재질·상태를 학습하며, 서로 다른 재질 부착물과 제거 대상 라벨을 혼동하지 않는다.
   동일 재질의 작은 부속품을 이물질 양성으로 만들지 않는다.
2. 원본·자동 라벨·독립 위치 증거·crop·학습 manifest의 연결과 보호 자료 분리를 검증한다.
   미확정 압착/라벨 등은 `-1`로 유지한다. 데이터 수·상태 0/1 지원·누수를 실제로
   검사한 뒤 하나의 후보 설정과 평가 기준을 고정한다.
3. 후보 학습과 calibration을 완료하고 기존 운영 모델과 같은 입력에서 비교한다.
   비닐/플라스틱, 종이/스티로폼 혼동과 빈 장면 오검출 등 실제 개선 여부를 보고한다.
   단순히 학습을 마쳤거나 기준을 통과했다는 이유로 성능이 향상됐다고 하지 않는다.
4. `evaluate_v4_candidate_judge.py`의 기존 기본 평가 하한을 낮추지 않는다.
   재질 balanced accuracy 0.90, 각 재질 recall 0.85, 배경 recall 0.90,
   물체 존재 recall 0.95, objectness balanced accuracy 0.925,
   기존 대비 각 recall 하락 최대 0.01을 유지한다. 표본 수·증거·정책 pin 등
   나머지 필수 검증도 모두 적용한다. 이는 목표 기준이며 현재 측정 성능이 아니다.
5. 신규 독립 blind와 실제 하드웨어의 이미지+무게 입력부터 결과·콜백 계약까지
   end-to-end 검증을 통과한다. 고정 41장, 이미 분석·보정한 사진, 모델 간 합의를
   신규 독립 정답으로 취급하지 않는다. 이 조건이 충족되기 전에는 최종 완료가 아니다.

## 지속 방식과 제한

- 실패하면 원문 로그와 불변 run을 보존하고 원인 분석 후 다음 안전한 개선을 진행한다.
  기존 실패 자료에 맞춰 평가 임계값을 낮추거나, 가짜 정답·음성 라벨·승인 SHA를 만들지 않는다.
- 운영 데이터 증분 선별·캐시·후보 재학습을 재사용한다. 사진이 늘어난다는 이유만으로
  자동으로 좋은 모델이라고 간주하지 않는다. 실시간 온라인 학습/무검증 자동 배포는 하지 않는다.
- 새 긴 NAS 단계는 하나씩 실행한다. 이미 실행 중인 동일 단계가 있으면 중복 시작하지 않는다.
  자동 감시에서는 한 번에 다음 한 단계까지만 진행하고 실제 epoch 완료 후 ETA를 계산한다.
- `production/Pi` 모델과 Spring 계약은 독립 하드웨어 gate 전 변경하지 않는다.
  NAS 재부팅, `timiroom-*` 변경 금지. `naco-ollama`와 `naco-ollama-worker2`는 중지 유지.
- 기존 pinned NAS SSH 키와 허가된 인증만 사용하며 비밀값은 출력·파일 저장하지 않는다.
  NAS용 인증을 Pi에 임의 재사용하지 않는다. 원본 로그·데이터는 삭제하지 않는다.
- 독립 하드웨어 촬영·접속 권한처럼 대신 수행할 수 없는 입력은 정확히 요청한다.
  그동안 안전하게 할 수 있는 데이터 준비·코드 연결·학습·calibration은 계속한다.
  입력 없이 가능한 일이 모두 소진되면 이를 완료로 바꾸지 않고 필요한 입력을 알린다.

## 현재 출발점

품질 assembly와 운영 source-evidence adapter의 NAS 실행·재검증은 완료했고
형식상 후보 9장/거부 11장을 유지했다. 그러나 실제 YOLO 및 원본 사진 진단에서
비닐·캔의 teacher 오라벨과 배경 대상 위치 오류를 발견하여 **9장 전체 학습 투입을 보류했다.**
`source_evidence_v1_20260904/material_semantics_hold.json`은 보존하고 새 독립
의미/전경 검증을 진행한다. 실제 YOLO crop/replay 연결 코드의 통과를 라벨 정확도로
표현하지 않는다.
후보 학습은 아직 시작하지 않았다. AIHub 기반 v4 91,938행은 9종+배경을 지원하지만
상태값은 모두 미확정이다. 별도 v7 상태 라벨을 실제 crop에 검증 없이 복사하지 않고
원본 근거·동일재질 부속품 모순·누수부터 확인한다. 자세한 실측은
`V7_STATE_SUPPORT_AUDIT_20260904.md`와 `OPERATIONAL_V4_HANDOFF_PLAN.md`를 따른다.

2026-09-04에는 batch/padding 불일치의 실제 GPU 대조 진단을 완료했고, 현재는
기존 불일치 CSV를 수정하는 대신 AIHub 원본 162,305장의 이미지·JSON을 실제로
확인하는 NAS 전량 검사를 진행 중이다. 샘플 36장은 원본 연결 검사에 통과했다.
자세한 최신 컨테이너, SHA, 진행률 및 다음 단계는
`AIHUB_REPLAY_NEXT_STEP_20260904.md`의 7~8절을 따른다. 원본 검사나 보호 이미지
지문 생성은 새 모델 학습 완료·성능 향상·배포 승인을 의미하지 않는다.
