## 파일 번호와 물체 정체성을 혼동하지 않는다

직접촬영 데이터는 개별 재활용품을 원거리 1장과 근거리 전후좌우 4장으로 촬영하도록
설명되어 있다. 파일 명명 규칙의 `@` 앞 번호는 **파일 고유 번호**, `@` 뒤 1~5는
촬영 방향이다. 문서는 이 파일 번호를 다섯 사진이 공유하는 물리적 객체 ID라고
정의하지 않는다. 그러므로 번호나 source SHA만으로 서로 다른 각도의 사진이 다른
물체라고 증명하거나 physical object/session 누수 검사가 끝났다고 하지 않는다.

## 상태 정답의 의미

설명서의 오염도 정의는 외부 오염 **또는 라벨 부착**을 같은 외부 이물질 항목으로
취급한다. 따라서 `DIRTINESS=이물질(외부)`를 서비스의 `FOREIGN_MATERIAL`이나
`REMOVE_LABEL` 한쪽 정답으로 직접 옮기면 두 상태가 섞인다. `오염없음`도 경미한
오염을 허용하므로 모든 물질·라벨 부재를 증명하지 않는다.

훼손도는 경미한 훼손까지 원형에 포함하고, 눈으로 구분되는 훼손과 평면에 가까운
완전압착을 구분한다. 이 정의를 기기의 압착 통과 기준과 대조하지 않은 채
`DAMAGE`만으로 서비스 압착 허용을 확정하지 않는다. 현재 원본 감사의
`annotation_dent`는 참고값이며 실제 상태 학습 필드는 계속 `-1`이다.

## 이번 연결 구현의 경계

현재 원본→파생 이미지/YOLO sidecar의 관계는 materializer의 `lineage.jsonl`에 있지만,
기존 crop generator/validator는 파생 JPEG와 sidecar만 읽었다. 별도의 원본 증거 reader로
report/cohort/lineage와 실제 원본 JSON·이미지·파생 파일의 SHA 및 split·정답을 연결한다.
crop의 `source_sha256`은 실제 replay 대상인 파생 JPEG SHA로 보존하고 원본은
`original_*` 필드로 별도 기록한다. 진단 partial 입력을 full 검증/학습 승인으로 바꾸지
않으며 최종 실제 하드웨어 독립 평가 조건도 그대로 유지한다.
