기준일: 2026-09-29

코드 기준: `af27c3e` (`main`)

Vision LLM: NAS Ollama `minicpm-v4.5:8b`

## 결론

기존과 동일한 AIHub 9종 × 30장 manifest를 Pi 운영 `pipeline.run` → NAS Vision LLM 경로로 다시 실행했다. 전체 정확도는 **255/270, 94.44%**로 기존 90.00%보다 4.44%p 높아졌고, 위험 거부품 recall은 **114/120, 95.00%**로 기존 86.67%보다 8.33%p 높아졌다. 미감지와 실행 오류는 모두 0건이었다.

유리 recall은 73.33%에서 93.33%, 형광등은 83.33%에서 96.67%, 비닐은 90.00%에서 93.33%로 개선됐다. 플라스틱 recall은 기존 76.67%를 보존했지만 목표 90%에는 미달한다. 이 평가는 이미 개선 판단에 사용한 AIHub 고정 세트이므로 신규 카메라 독립 승인으로 해석하지 않는다.

## 최종 구조

- Vision LLM이 계속 최종 품목 결정권을 갖는다.
- 1차 LLM은 YOLO 후보와 무게를 받지 않고 이미지로 독립 판정한다.
- 고신뢰 YOLO와 1차 LLM이 정해진 재질 쌍에서 충돌할 때만 2차 Vision LLM 판정을 실행한다.
- 유리→PET/플라스틱, 비닐→종이, 스티로폼→종이 방향은 전체 형태와 crop을 함께 보는 형태 우선 프롬프트를 사용한다.
- 반대 방향과 캔·램프 등은 후보별 제조 단서를 쓰는 제한 프롬프트를 사용한다.
- YOLO는 bbox와 충돌 감지용 참고 신호이며 최종 정답으로 강제하지 않는다.

형태 우선 지침을 모든 1차 요청에 적용한 중간안은 플라스틱을 종이·스티로폼으로 과분류했다. 최종안은 해당 지침을 실제 충돌 방향의 2차 판정에만 제한해 플라스틱 성능을 보존했다.
