## 실행 경로

1. Pi 운영 컨테이너가 현재 `ModelRegistry`로 NCNN YOLO를 로드했다.
2. API endpoint가 호출하는 동일한 `pipeline.run`을 사용해 이미지와 고정 무게 `20.0g`을 입력했다.
3. YOLO bbox/crop, 원본 fallback, 충돌 재판정, NAS Vision LLM, 규칙 엔진을 모두 통과시켰다.
4. 벤치마크 270건이 Spring 운영 데이터로 전송되지 않도록 HTTP 계층과 Spring callback만 제외했다.

따라서 품목 판정과 NAS 호출 시간은 실제 production inference 경로이며, 네트워크의 HTTP 직렬화·Spring callback 시간은 포함하지 않는다. 고정 무게는 상태 판정용 실제 정답이 아니므로 품목 정확도는 `classification.class_name`만으로 계산했다. PET 정답은 운영 계약에 따라 응답 `plastic / class_id=3`을 정답으로 인정했다.
